Improve the structure and spacing of the blog post at: $ARGUMENTS

## Instructions

1. Read the specified blog post file
2. Analyze the current structure and paragraph organization
3. Improve readability through better spacing and structure
4. Do not change the meaning, tone, or content of the writing

## Structure Improvements

### Paragraph Breaks

- **Break up long paragraphs**: Split paragraphs longer than 4-5 sentences into smaller, focused chunks
- **One idea per paragraph**: Each paragraph should convey a single main point
- **Preserve intentional structure**: Respect the author's original paragraph breaks when they serve a purpose

### Visual Rhythm

- **Vary paragraph length**: Mix short punchy paragraphs with medium-length ones to create rhythm
- **Use single-sentence paragraphs sparingly**: For emphasis or transitions
- **Add breathing room**: Ensure adequate spacing between sections and ideas

### Section Organization

- **Check heading hierarchy**: Ensure headings follow a logical structure (h2 → h3 → h4)
- **Balance section length**: Avoid sections that are disproportionately long or short
- **Add section breaks if needed**: Insert headings where a new topic begins but lacks a clear marker

### List Formatting

- **Convert dense enumerations to lists**: When a paragraph lists multiple items, consider using bullet points
- **Keep lists focused**: Each list should have a clear purpose
- **Don't over-list**: Preserve narrative flow; not everything needs to be a bullet point

### Code and Examples

- **Separate code from explanation**: Ensure prose and code blocks have clear boundaries
- **Group related code**: Keep related code snippets together rather than scattered

## What NOT to Change

- The actual content and meaning
- The author's voice and tone
- Technical accuracy
- Links and references
- Frontmatter

## Output Format

### Structure Analysis

Brief assessment of the current structure:
- What works well
- What could be improved

### Changes Made

List the specific structural changes:
- Paragraphs split (quote first line of each)
- Sections reorganized
- Lists created
- Headings adjusted

### Revised Version

Provide the complete revised post (excluding frontmatter) with improved structure and spacing.
